Home Fusion

Browse your library by genre, rating, release date and collection from the home screen.

Genres row
One card per genre, such as Action, Comedy or Romance.
Shuffles the genre cards each time Home loads. Otherwise genres are sorted by number of titles.

Hidden genres
These are the genres currently found in your library. Checked genres will not get a card in the Genres row.

Ratings row
Top 50, 8 - 10 Stars, 7, 6, 5, 4 Stars and 1 - 3 Stars.

Release Date row
Latest titles, then each decade found in your library.

Collections row
One card per collection, opening its Jellyfin details page.
Shuffles the collection cards each time Home loads. Otherwise collections are sorted by name.
Use 0 for no limit. View all always shows every collection.

Content
Which library items the Genres, Ratings and Release Date rows are built from. Collections are loaded separately for the current user.
Select at least one: movies or series.
Hides the number of titles in Collections, Genres, Ratings and Release Date cards.

Interface tweaks
Clean up annoying Jellyfin Web items. Applies to all users after a page refresh.
Hides standalone movie years on Jellyfin cards and movie years in HomeFusion grids. TV show details remain visible.
Positions apply to all users. If a user's Home does not show the selected section, the row appears at the bottom instead. Rows sharing a position keep the order Collections, Genres, Ratings, Release Date.

The rows are injected automatically into the Jellyfin Web home screen. Native clients are not modified.
